# CV — Bruno Ochoa

Sitio web personal desarrollado como proyecto para la cátedra Wischñevsky 2026,
que presenta mi perfil profesional, formación, habilidades y trabajos destacados
como estudiante de Diseño y Comunicación Visual.

## Tamaño de diseño
Este sitio fue diseñado y probado principalmente para pantallas de escritorio,
con un ancho de referencia de 1200px
Probado en una resolución de pantalla de 1920x1080.

## Tecnologías
* HTML5
* CSS
* Flexbox (navegación, galería de imágenes, distribución de habilidades, íconos de contacto)

## Secciones
* Hero — nombre y presentación breve, con imagen de fondo
* Sobre mí — descripción personal y galería de trabajos destacados
* Estudios — formación académica
* Habilidades — listado de herramientas y competencias
* Experiencia — línea de tiempo de trabajos y proyectos
* Contacto — enlaces a Behance y correo electrónico
